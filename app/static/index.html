    입력이 끝난 뒤, 음성이 시작될 때까지

    텍스트는 전송 시점, 음성은 발화 종료를 감지한 시점부터 첫 음성 시작 이벤트까지 측정합니다. 네트워크와 음성 처리 경로가 포함된 근사치이며, 실제 스피커 재생 시점이나 LLM만의 연산 시간과는 차이가 있습니다.

    서로 같은 기준끼리 비교해요

    OpenAI는 발화 종료 이벤트, ElevenLabs는 VAD 점수의 발화→침묵 전환을 사용합니다. ElevenLabs에서 종료 신호를 얻지 못하면 전사 수신 시점으로 측정하고, ‘전사 · 참고’에 따로 표시합니다. 전사 수신만으로 응답 완료를 기록하지 않습니다.

    질문과 환경을 맞춰 주세요

    공통 테스트 문장을 보내면 입력 길이를 맞추기 쉽습니다. 음성 테스트는 같은 질문과 마이크를 사용하세요. 첫 인사, 응답 전에 재개한 발화, 연결 종료, 오류와 45초 초과는 평균에서 제외합니다. 음성이 시작된 뒤의 끼어들기는 이미 측정한 지연을 유지합니다.

    모델별로 누적, 언제든 다시 확인

    카드는 현재 설정된 모델의 기록을 표시합니다. 변경 전 모델은 턴별 기록과 내보내기에 남습니다. P95는 작은 표본에서 최댓값과 같을 수 있습니다. 브라우저의 최근 600개 기록을 유지하며, JSON에는 모든 입력 기준의 기록을 담습니다.
